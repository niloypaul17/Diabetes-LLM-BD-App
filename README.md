# DiaLLM-BD — corrected prototype

## What changed from your submitted version

1. **Fixed a target-leakage bug in `train_model.py`.** The dataset's target column
   was auto-detected and matched `family_diabetes` (family history) instead of the
   real outcome column `diabetic`. That let the actual `diabetic` label sit in the
   input features, which is why validation accuracy was ~99%. The target is now
   pinned explicitly (`TARGET_COLUMN_OVERRIDE = "diabetic"`). **You must retrain**
   — the old `models/*.pkl` and `outputs/*.csv` in this zip are stale and will be
   overwritten when you run `train_model.py`.
2. **Deployment model is now fixed to XGBoost** (recall-first), independent of
   whichever model wins the validation table by F1/accuracy — matching what the
   paper argues in Section 4.1 (a high-ROC-AUC model with ~26% recall on the
   diabetic class is unsafe for screening). The full model comparison table is
   still produced for the paper.
3. **Prediction Explanation tab** now shows a real per-patient SHAP breakdown
   (which values pushed the estimate up/down, with a waterfall chart), not just
   a templated sentence — and can export the result as **PDF, DOCX, PNG, or JPEG**.
4. **Chatbot** is now retrieval-grounded: every answer cites a real source (WHO /
   IDF / ADA fact sheets) and, if you install Ollama locally, drafts its reply
   with a real local LLM using that retrieved context. No paid API key needed;
   a slot (`remote_llm_generate` in `rag_chatbot.py`) is left for Gemini/OpenAI
   if you add one later.
5. **New "Nearby Doctors & Hospitals" tab** — free OpenStreetMap lookup by typed
   location (optionally by browser geolocation if you install one extra package).

## Setup on Windows

1. Install **Python 3.10 or 3.11** from python.org (check "Add to PATH" during install).
2. Install **VS Code** (code.visualstudio.com) and its **Python extension** — yes,
   this runs fine in VS Code. Open this folder in VS Code (`File > Open Folder`).
3. Open a VS Code terminal (`` Ctrl+` ``) in this folder and run:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. **Retrain the model** (required — see above):
   ```
   python train_model.py
   ```
   This prints the full validation table and final test metrics, and writes
   `models/*.pkl` and `outputs/*.csv`. **Copy that printed output and the
   `outputs/` folder back so the paper's numbers can be updated.**
5. **Run the app:**
   ```
   streamlit run app.py
   ```
   It opens at `http://localhost:8501` in your browser.

## Optional: local LLM chatbot via Ollama (free, no key)

1. Download Ollama from https://ollama.com/download (Windows installer).
2. In a terminal: `ollama pull llama3.1` (about 4.7GB, one-time).
3. Leave Ollama running in the background. The chatbot tab auto-detects it — no
   config needed. If it's not running, the chatbot still works using the
   retrieval-template fallback, just without free-form LLM phrasing.

## Optional: one-click browser geolocation

```
pip install streamlit-js-eval
```
Without this, the Nearby Care tab still works fully via typed location.
